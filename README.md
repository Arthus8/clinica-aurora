# Clínica Aurora

Landing page institucional para uma clínica fictícia, desenvolvida com HTML, CSS e JavaScript.

## Sobre o projeto

A página apresenta uma identidade visual completa para a Clínica Aurora, com:

- hero section com destaque institucional;
- seção de serviços;
- apresentação da equipe fictícia;
- formulário de contato com validação no navegador;
- layout responsivo para desktop e mobile.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como abrir

1. Abra a pasta do projeto.
2. Dê dois cliques em `index.html` para visualizar a página no navegador.
3. Opcionalmente, você pode servir o projeto em um servidor web estático local.

## Observações

- As fotografias são carregadas externamente a partir do Pexels.
- A página foi pensada como um projeto estático, sem backend, banco de dados ou dependências de instalação.
- O formulário simula envio e não processa dados reais.
