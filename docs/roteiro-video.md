# Roteiro de apresentação — até 5 minutos

**Duração planejada: 4 minutos e 40 segundos**, deixando 20 segundos de margem. Prepare as abas do site, do repositório e do código antes de gravar. Confira as fotografias e use somente dados fictícios no formulário. O roteiro é uma base de fala, não uma gravação nem uma comprovação de publicação.

| Tempo | Mostrar | Conteúdo da fala |
|---|---|---|
| 0:00–0:25 | Página inicial | Seu nome, disciplina e escolha do Projeto 01. Apresente a Clínica Aurora como fictícia e explique o objetivo institucional. |
| 0:25–1:05 | Serviços | Mostre as quatro áreas de atendimento, as fotografias e suas descrições. Explique que a página organiza a informação para o visitante. |
| 1:05–1:40 | A clínica e equipe | Mostre os três membros com foto e cargo. Destaque que nomes, funções e clínica são fictícios e as fotos são ilustrativas. |
| 1:40–2:25 | Formulário | Tente enviar sem preencher; mostre a validação. Preencha Pessoa de Teste, teste@example.com, Brasília, DF. Simule o envio e leia a mensagem de que nada foi enviado ou armazenado. |
| 2:25–3:00 | Tela estreita, menu e FAQ | Reduza a janela ou use o modo de dispositivo do navegador. Abra/feche o menu e uma pergunta. Mostre que as seções continuam acessíveis. |
| 3:00–3:40 | Estrutura do código e README | Mostre `index.html`, `style.css` e `main.js`. Explique estrutura, apresentação e interações. Mostre que a execução consiste em extrair o ZIP e abrir o HTML, com internet para as fotos. |
| 3:40–4:10 | EAP e testes | Explique os marcos das semanas 3, 6 e 9 e cite dois testes realizados. Diferencie evidências verificadas de itens que ainda estavam pendentes. |
| 4:10–4:40 | Repositório publicado e encerramento | Mostre o código no GitHub e o site online, caso publicado. Feche resumindo os requisitos atendidos e o escopo sem backend. |

## Exemplo de abertura

“Meu nome é [seu nome] e este é o projeto Clínica Aurora. Escolhi o Projeto 01, uma landing page estática, para apresentar os serviços e a equipe de uma clínica fictícia. A página foi desenvolvida com HTML, CSS e JavaScript, sem backend.”

## Exemplo para explicar o formulário

“Esses campos representam um primeiro contato, mas aqui o objetivo é somente demonstrar a interface. O navegador valida o preenchimento e o JavaScript impede o envio. A mensagem informa que nenhum dado foi enviado ou armazenado. Não há cadastro, consulta ou agendamento.”

## Antes de publicar

Assista à gravação inteira, confirme a duração, a legibilidade da tela e o áudio. Evite mostrar notificações, e-mails, senhas ou dados reais. Publique no canal permitido pelo enunciado e abra o link em janela anônima. Só então insira o endereço em `entrega.html` e gere o PDF final.
