Resumo da solução

Página institucional de uma clínica fictícia, com descrição dos serviços, fotografias ilustrativas, três perfis fictícios de profissionais, navegação responsiva e formulário estático com nome, e-mail, cidade e estado. Desenvolvida com HTML, CSS e JavaScript, sem backend ou banco de dados.

As fotografias são carregadas do Pexels e precisam de internet. O formulário não envia mensagens, não armazena os dados preenchidos e não cria agendamentos.

Verificação de acesso aos links: pendente. Este modelo não comprova publicação do projeto ou do vídeo.
